# Implementation gates

A milestone is not complete until its evidence is recorded.

- **G1 Live game:** one headless FightingICE Random-vs-Random run completes and both traces pass pair audit.
- **G2 Biological data:** canonical source, license/terms, source checksum, preprocessing, processed-file checksums, and graph fingerprint are recorded.
- **G3 Fixed-connectome learner:** repeated independent training seeds improve against a fixed held-out baseline; no topology claim yet.
- **G4 A/B topology:** biological and matched rewired controllers use identical budgets and evaluation sets; effect and uncertainty are reported.
- **G5 Plastic connectome:** internal existing-edge parameters are trainable while topology/sign constraints remain enforced and separately audited.
- **G6 Confirmatory:** hypotheses, exclusions, stopping, seeds/evaluation protocol, and effect metric are frozen before the final run.
