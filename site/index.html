Connectome Fighter Lab

A reproducible testbed for asking whether connectome-constrained controllers learn competitive policies differently from matched control networks in FightingICE.

Game target
FightingICE 7.1
Python bridge
pyftg 2.3
Current stage
Integration

Primary experiment

Compare a verified Drosophila-derived wiring topology against degree/sign-preserving rewired controls under identical observations, actions, reward, training budget, seeds, and evaluation opponents.

Current status

The repository contains the game bridge, trace auditing, graph/control scaffolding, offline tests, Docker configuration, and experiment protocol. Real connectome ingestion and PPO/self-play training remain separate milestones.

Reproducibility rule

Mock tests, synthetic graphs, and live FightingICE runs are recorded as distinct evidence classes. Synthetic fixtures must never be reported as biological results.
