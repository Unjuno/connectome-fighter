How it is intended to run

GitHub Actions is used in bounded chunks, not as one immortal process: restore checkpoint → train → checkpoint → evaluate → export replay/metrics → deploy Pages → resume on the next run. The current hosted-runner job ceiling is six hours, so true near-24/7 compute should eventually move to a self-hosted runner while keeping the same checkpoint and spectator contracts.

Evidence boundary

Continuous learning demonstrates a persistent competitive agent. It does not by itself show that the biological Drosophila topology is superior. That claim requires the separate matched-rewire A/B protocol.
